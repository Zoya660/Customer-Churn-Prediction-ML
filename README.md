# Customer Churn Prediction using Machine Learning

This project predicts telecom customer churn using Machine Learning.

## Models Used

- Logistic Regression
- Random Forest

## Results

Logistic Regression performed best with:

- Accuracy: 80.28%
- Recall: 52.42%
- ROC-AUC: 84.03%

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Google Colab
